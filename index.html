Webhook Configuration

How n8n Test Webhooks Work:

When using webhook-test, n8n only accepts one request per time you click "Listen for test event" inside your canvas. Once it fires, you must activate the workflow in n8n and toggle to Production mode here for 24/7 continuous chatting!

n8n Connection Diagnostics

Quick Self-Check:
  • If HTTP 404: You are in test mode and haven't clicked "Listen for test event", or the node is disabled.
  • If Empty Response: Make sure your n8n workflow ends with a Respond to Webhook node with Response Body set to your AI output.
  • If CORS Error: Ensure n8n is allowed to accept browser fetch requests or test using the cURL below.
